Selected Projects

Custom FPGA Architecture & Bitstream Programming →

Designed a custom FPGA architecture from scratch in Verilog, featuring Configurable Logic Blocks (CLBs), LUT4s, and a programmable routing matrix. Performed manual synthesis and place-and-route, generating a 38-bit configuration bitstream to map logic onto the FPGA fabric. Verified with a self-checking SystemVerilog testbench.

Verilog SystemVerilog Vivado Computer Architecture

Single-Cycle MIPS Processor (ACA-MIPS) →

Implemented the complete datapath and combinational control unit for a 32-bit Single-Cycle MIPS processor. Extended the baseline architecture to support zero-extension, LUI, BNE, and Jump instructions. Verified using cycle-accurate insertion sort benchmarks.

Verilog ModelSim Datapath Design ISA

Hardware-Accelerated Edge Detection on Zynq SoC

Engineered a real-time image-processing system on a Xilinx Zynq-7000 SoC. Implemented the Sobel edge-detection algorithm in hardware (PL) and a bare-metal C application on the PS to manage the camera interface and data flow.

Zynq-7000 AXI Bare-metal C Image Processing

UVM Verification of an RTC Clock-Generation Circuit

Built a Universal Verification Methodology (UVM) testbench to verify a submodule of a Real-Time Clock (RTC) clock-generation circuit, implementing agents, drivers, monitors, and scoreboards.

SystemVerilog UVM Verification
